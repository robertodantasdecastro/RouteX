# RouteX Mac Cyberdeck UI Sketches

These static sketches define the visual direction for the new RouteX `cyberdeck`
interface mode. They are design references, not production UI.

## Sketches

- `01-cockpit.html`: daily operational cockpit with daemon status, active route,
  privacy gate, Cursor setup and quick recovery actions.
- `02-route-lab.html`: routing simulator with profile selection, route preview,
  fallback chain and cloud/local policy visibility.
- `03-settings-appearance.html`: settings surface for switching between
  `cyberdeck` and `classic`, with a compact shell preview.

## Visual Direction

- macOS utility app structure: compact chrome, left rail, dense command strips.
- Cyberpunk restraint: graphite base, cyan/green status language, amber warnings
  and violet only as a secondary accent.
- Operational density: tables, status rows and compact panels replace large
  webpage-like cards.
- Brand usage: RouteX mark is present in the rail and title context, not as a
  giant hero element.
